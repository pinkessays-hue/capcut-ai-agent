# 경쟁사 Meta 광고 소재 분석 요약

> 10개 브랜드 · 111개 소재(이미지 58, 영상 53) 기준
> 분석 시점: 2024년 하반기 ~ 2025년 상반기 집행 소재

## 분석 대상 브랜드

폴인퍼니, 레이디가구, 더필더디자인, 보르네오, 시디즈, 리바트, 한샘, 일룸, 에이스침대, 시몬스

## 핵심 인사이트 13가지

1. 궁금증·질문형 카피가 상위 소재에서 1.9배 과대 대표 — 가장 강력한 후킹 전략
2. 가격 반전형("이 가격에 이 퀄리티?")이 중소 브랜드에서 특히 효과적
3. 모션(슬라이드·확대) > 정적 이미지 (A/B 테스트 반복 확인)
4. 실고객 컷 > 모델 컷 (신뢰 전환에서 우위)
5. 결과 카피("거실이 달라졌다") > 기능 카피("3단 높이 조절")
6. 시즌 합성 이미지 > 카피 배너 (노출 효율)
7. 9:16 세로 영상이 피드 4:5 대비 노출 효율 높음
8. 15초 이내 영상이 최적 — 길어질수록 이탈
9. 0-1초 훅이 전체 성과를 좌우
10. 키즈 카테고리에서 안전·인증 소구가 부모 타깃에 강력
11. 소파·식탁에서 실물 배치 컷이 구매 전환 핵심
12. 침대·매트리스에서 수면 환경 공감형 오프닝이 상위 점유
13. DPA 카탈로그 + 리타깃팅 조합이 대형 브랜드의 기본 구성

## 카피 전략 분류 (10가지)

| 유형 | 상위 소재 점유율 | 대표 활용 |
|------|-----------------|----------|
| 궁금증·질문형 | 1.9x 과대 대표 | "이 가격이 실화?" |
| 문제 제기형 | 높음 | "좁은 거실, 포기했었는데" |
| 효과·결과형 | 높음 | "거실 분위기가 달라졌어요" |
| 가격 반전형 | 중소 브랜드 집중 | "50만원대에 세라믹 식탁?" |
| 긴급·희소형 | 중간 | "이번 주까지만 이 가격" |
| 후기·사회적 증거형 | 중간 | "3,000명이 선택한" |
| 경고·금지형 | 낮지만 CTR 높음 | "이거 모르고 매트리스 사지 마세요" |
| 스펙 나열형 | 낮음 | 기능 위주 |
| 브랜드 슬로건형 | 대형 브랜드 위주 | 인지도 캠페인 |
| 감성·라이프스타일형 | 중간 | 분위기 연출 |

## A/B 테스트 주요 결과

| 비교 | 승자 | 근거 |
|------|------|------|
| 모션 vs 정적 | 모션 | 동일 제품에서 반복 확인 |
| 실고객 vs 모델 | 실고객 | 신뢰 지표 우위 |
| 결과 카피 vs 기능 카피 | 결과 카피 | 상위 소재 점유율 |
| 시즌 합성 vs 카피 배너 | 시즌 합성 | 노출 효율 |
| 전신 컷 vs 제품 클로즈업 | 상황에 따라 다름 | 카테고리별 상이 |

## 15초 영상 구조 (표준)

```
0-1초   훅 (자막 + 시선 끄는 장면)
1-4초   상황 설정 (공감 or 문제)
4-10초  근거 제시 (기능 시연, 실물 컷, 비교)
10-13초 신뢰 보강 (후기, 인증, 숫자)
13-15초 혜택 + CTA (가격, 링크, 행동 유도)
```

## 이미지 레이아웃 패턴 (9가지)

1. 제품 단독 컷 (배경 제거)
2. 인테리어 배치 컷 (실제 공간)
3. 비포/애프터 분할
4. 다각도 그리드 (2-4컷)
5. 시즌·무드 합성 (계절감 배경)
6. 가격 강조 배너
7. 텍스트 오버레이 (카피 중심)
8. 카탈로그 스타일 (DPA용)
9. 사용자 후기 캡처

## 영상 패턴 (9가지)

1. 가격 훅형 (가격 반전으로 시작)
2. 공감 시작형 (생활 불편 제기)
3. 데모·기능 시연형 (제품 조작)
4. 실고객 인터뷰형 (리얼 후기)
5. 언박싱·설치형 (개봉 과정)
6. 룸투어·쇼룸형 (공간 탐색)
7. 비교형 (경쟁 제품 대비)
8. 타임랩스형 (변화 과정)
9. ASMR·감각형 (소재 질감)
