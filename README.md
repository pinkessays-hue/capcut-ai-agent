# CapCut AI 편집 에이전트

제품 영상을 넣으면 **장면을 나누고 → 나쁜 구간을 걸러내고 → 좋은 컷을 골라 → 숏폼 순서로 배치**해 줍니다.
API 키나 유료 서비스 없이 내 PC에서만 동작합니다.

## 처음 한 번만 (설치)
1. Python 설치: https://www.python.org/downloads/ (설치 첫 화면에서 **Add Python to PATH** 체크)
2. 이 폴더의 `setup.bat` 더블클릭 → 설치가 끝나면 창이 멈춥니다.

## 사용법
1. `input` 폴더에 영상(mp4, mov 등)을 넣는다.
2. `run.bat` 더블클릭. (또는 영상 파일을 `run.bat` 위로 끌어다 놓기)
3. `output/영상이름/` 폴더에서 결과 확인.

| 결과 파일 | 내용 |
|---|---|
| `reels_draft.mp4` | 추천 순서로 이어 붙인 세로(9:16) 숏폼 초안 |
| `clips/` | 컷별 영상 (번호 순서대로 CapCut에 가져오면 바로 편집 가능) |
| `plan.md` | 추천 컷 순서, 제거 추천 구간과 이유, 전체 장면 점수표 |
| `thumbnails/` | 장면별 미리보기 이미지 |
| `scenes.json` | 분석 원본 데이터 |

## 어떻게 판단하나요 (AI가 아니라 규칙 기반)
- **장면 전환**: 화면 색 분포가 크게 바뀌는 지점
- **제거 추천**: 너무 짧은 컷 / 흐린 컷 / 너무 어두운 컷 / 화면 변화가 거의 없는 컷
- **좋은 컷 선별**: 선명도 + 움직임 + 밝기 점수
- **순서**: 점수 1위 컷을 맨 앞(훅), 나머지는 촬영 순서(조립·변형 과정 흐름 유지)
- 판단 결과는 참고용입니다. 마음에 안 들면 `plan.md`와 `clips`를 보고 CapCut에서 조정하세요.

## 설정 바꾸기 (`config.json`, 메모장으로 열기)
- `목표_길이_초`: 숏폼 길이 (15, 30 등)
- `한_컷_최대_길이_초`: 컷 하나당 최대 길이
- `세로영상_변환`: `crop`(꽉 채우기) / `fit`(검은 여백) / `off`(원본 비율)
- `장면전환_민감도`: 낮출수록 장면을 더 잘게 나눔
- 컷이 너무 많이 제거되면 `흐린_컷_제거_기준` 등의 숫자를 낮추세요.
